# Maturity Level 1

Maturity Level 1 is the first level of the LMOrbits platform. It is a simple and easy to use platform for building a simple app and application on top of it with openly available llm.

## Prerequisites

- [gh](https://cli.github.com/)
- [git](https://git-scm.com/)
- [uv](https://docs.astral.sh/uv/)
- [docker](https://www.docker.com/)

## Steps

in Order to implement this level you can follow the following steps:

1. fork the app project template to have a base repo for all of your app stacks.

```bash
gh repo fork https://github.com/LMOrBits/app_projects.git --clone --remote
```

2. navigate to the projects folder projects/[py|js|ts] and add your app stack as a submodule in the repo. then you can fork the repo and add your app stack as a submodule in the repo (based on the app stack type you have in mind). this can be based on a template app stack or based on any open source app stacks.

```bash
cd projects/py
uv sync
uv run task app-stack-new APP_NAME=<app-stack-name>
```

or

```bash
cd projects/py
gh repo fork LMOrbits/<app-stack-name> --clone=false
git submodule add LMOrbits/<app-stack-name> <app-stack-name>
git commit -m "Add submodule <app-stack-name>"
```

3. add your appdeps.env based on the appdeps.example.env

```bash
cd <app-stack-name>
mv appdeps.example.env appdeps.env
```

```bash
code appdeps.env
```

4. run the inferecne

```bash
uv sync
uv run pyapp-cli run
uv run inference
```

now you will see the inference result in a the terminal along with the link to the observation go to that url to see the steps. specially with the one that has the same name as the appstack name.

5. now you can start to build your app on top of the appstack.

6. in order to build the application on top of it you can reffer to the [application](../how-to/development/application/README.md) section.
